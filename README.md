一个极简、有趣的单文件动画表情交互页面。所有代码（HTML, CSS, JS）均浓缩在一个文件中，实现悬浮、渐变色与用户交互。
A minimal and fun single-file animated emoji interactive page. All code (HTML, CSS, JS) is condensed into one file, achieving floating, gradient color effects, and user interaction.

## ✨ 超短代码 | Ultra-Short Code
**核心亮点**：这是一个完全独立的 HTML 文件，包含全部样式和逻辑，**代码仅约100行**。非常适合学习、修改或快速集成到项目中。
**Key Highlight**: This is a completely standalone HTML file containing all styles and logic, with **code of only about 100 lines**. Perfect for learning, modifying, or quick integration into projects.

## 🎮 功能特性 | Features
*   **动态动画**: 表情符号会自动上下浮动并循环变换颜色。
    *Dynamic Animation*: The emoji automatically floats up and down and cycles through colors.
*   **交互控制**:
    *Interactive Control*:
    *   点击表情可暂停/继续动画。
        *Click the emoji to pause/resume the animation.*
    *   可输入自定义表情符号（最多5个字符）并应用。
        *Input a custom emoji (max 5 characters) and apply it.*
*   **速度调节**: 提供“慢”、“中”、“快”三档动画速度。
    *Speed Adjustment*: Offers three animation speeds: "Slow", "Normal", "Fast".
*   **随机表情**: 一键从预设列表中随机切换一个表情。
    *Random Emoji*: Switch to a random emoji from a preset list with one click.

## 🛠️ 技术栈 | Tech Stack
*   HTML5
*   CSS3 (使用 `keyframes` 和 `filter` 实现动画)
    *(Using `keyframes` and `filter` for animations)*
*   Vanilla JavaScript (纯原生JS，无任何依赖)
    *(Pure vanilla JS, no dependencies)*

## 🚀 快速开始 | Quick Start
1.  将代码保存为 `index.html`。
    *Save the code as `index.html`.*
2.  直接在浏览器中打开即可运行。
    *Open it directly in any browser to run.*

点击页面上的表情、按钮，或在输入框中尝试输入新的表情（如 🍕、🤖、🎉）并按回车/点击“应用”。
Click the emoji or buttons on the page, or try entering a new emoji (like 🍕, 🤖, 🎉) in the input box and press Enter/click "Apply".
